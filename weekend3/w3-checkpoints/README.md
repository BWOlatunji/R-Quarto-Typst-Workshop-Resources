# Facilitator checkpoints

One folder per step of `sitrep-facilitator-guide.docx`. Each folder is the project exactly
as it should look **after** that step, and renders on its own:

    cd step-09
    quarto render sitrep.qmd

Use a folder to rescue a participant who has fallen behind: copy its three files
(`sitrep.qmd`, `typst-template.typ`, `typst-show.typ`) over theirs.

`step-24` is identical to the finished template in the parent folder.
Step 0 has blank `.typ` files, and Step 7 looks the same as Step 6 (R setup chunk only).
